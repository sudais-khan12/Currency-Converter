# 💱 Currency Converter

A clean, responsive, and user-friendly web application built to calculate and convert currencies using live exchange rates in real time. 

🔗 **Live Preview:** [sudais-khan12.github.io/Currency-Converter](https://sudais-khan12.github.io/Currency-Converter/)

---

## ✨ Features
* **Live Exchange Rates:** Fetches up-to-date conversion rates dynamically.
* **Country Flags & Codes:** Seamless currency selection paired with respective national flags.
* **Swap Functionality:** Quick toggle to swap between "From" and "To" currencies instantly.
* **Responsive UI:** Minimalist card design styled with clean CSS for both desktop and mobile screens.

---

## 💻 Tech Stack
* **HTML5:** Semantic markup structure.
* **CSS3:** Custom responsive styling and layout design.
* **JavaScript (ES6):** DOM manipulation, event handling, and API integration (`app.js`, `codes.js`).
